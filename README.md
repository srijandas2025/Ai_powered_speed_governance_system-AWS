\# AI-Powered Smart Speed Governance System for Indian Roads 🇮🇳



This project proposes an AI-based traffic speed monitoring and governance system designed specifically for Indian road conditions.



\## Key Features

\- AI-based vehicle detection and speed estimation

\- Overspeeding violation detection

\- Real-time alerts

\- India-specific road adaptability

\- Multilingual support (Hindi \& Bengali)

\- Cloud-native architecture using AWS



\## Tech Stack

\- Computer Vision (OpenCV)

\- Machine Learning

\- AWS (S3, Lambda, Rekognition, DynamoDB, SNS)

\- Python



\## Purpose

Built for the \*\*AWS AI for Bharat Contest\*\* to improve road safety using responsible AI.
